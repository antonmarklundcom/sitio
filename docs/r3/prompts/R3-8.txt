Definition of done:
The admin wrapper div in src/app/admin/layout.tsx carries a data-admin-theme attribute read from the cookie on the server: light, dark, or absent when no cookie. Tokens are defined so that: with data-admin-theme=dark the current dark values apply; with data-admin-theme=light the light values apply; with the attribute absent the system preference decides via prefers-color-scheme (dark values by default, light values under prefers-color-scheme light). Tailwind classes such as bg-admin-bg keep working unchanged because only the variable values move; if the tokens must live on the wrapper instead of :root for that to work, do that and keep the @theme inline mapping.
The wrapper also sets color-scheme (light or dark) so native form controls and scrollbars match.
src/components/admin/theme-toggle.tsx is a small button in the header showing the current mode with an accessible label (aria-label in Spanish: Cambiar a modo claro / Cambiar a modo oscuro); clicking calls a server action that writes the cookie (httpOnly false is fine, sameSite lax, path /, max-age one year) and calls revalidatePath('/admin', 'layout') so the page re-renders in the new theme without a manual reload.
src/lib/admin-theme.ts exports the cookie name, the union type, and parseAdminTheme(value: string | undefined) returning light, dark or null; tests/unit/admin-theme.test.ts covers the three outcomes and a garbage value.
