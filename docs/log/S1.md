# S1 — Produkter (PR-14)

## Built
- `src/lib/product-form.ts`: zod-schema, `PRODUCTS_MAX = 60`, samma prisfält
  som menyn (tomt → "A consultar").
- `src/db/product-queries.ts`: `getProducts`, `publicProducts` (filtrerar
  `isVisible`), `ownedProduct` (tenant-scoped).
- `src/app/mi-sitio/product-actions.ts`: `productContext()` (samma mönster
  som `menuContext()` — modulen kontrolleras på servern, aldrig bara i UI:t),
  save/delete/toggle/move.
- `src/components/mi-sitio/owner-products.tsx` + `src/components/site/
  products-section.tsx` (`<SiteProducts>`, id `catalogo` — comercio använder
  redan `id="productos"` för destacados).
- `<SiteProducts>` monterad i `comercio-theme.tsx` (enda temat denna fas,
  §6.1); övriga teman: S6.
- `theme.css`: `/* == S1 == */`-block (delad grid-primitiv). `comercio.css`:
  hover-override på hairline-korten.
- `site-queries.ts`, `types.ts`, `render-site.tsx`, `mi-sitio/page.tsx`:
  produkterna följer samma på/av-mönster som menyn.
- `modules.ts`: `plannedIn` borttagen för `products`.
- `scripts/theme-preview.tsx`: demo-produkter + modulen på, annars hade QA-
  gaten aldrig visat den nya sektionen.
- Enhetstest `tests/unit/product-form.test.ts` (9 fall), rök
  `tests/smoke/products.mjs` (16 kontroller).

## Decisions
- **`<SiteProducts>` fick id `catalogo`, inte `productos`.** Comercio
  använder redan `id="productos"` för sektionen med destacados
  (`business.servicesJson`) — två `id="productos"` på samma sida hade
  brutit ankarlänkar.
- **Röktestet byter tillfälligt business 1:s tema till `comercio`** (och
  återställer det på slutet). Seedens business 1 kör `servicios`, som inte
  ansluter `<SiteProducts>` förrän S6 — utan bytet hade "dolt/synligt"-
  kontrollerna aldrig kunnat skilja på rätt och fel utfall.
- **Ingen `data-ev-view`** på produktsektionen: `products` har inget
  vy-event i analytics-enumet denna runda (plan §1.1, inga migreringar).
  Testat explicit i smoke-filen.
- Produktbilder (`media.kind = "product"`) är avsiktligt utanför scope,
  som menyns rätter i PR-13.

## Known issues
- Produktkort har ingen bild än (se ovan) — ren text- och prislista.
- Comercio-temat visar nu både `<SiteProducts>` (katalog) och `<SiteMenu>`
  (den generiska "Nuestra lista") när båda modulerna är på. Ingen konflikt,
  men dubblerar informationen om en kund slår på båda; ett beslut för S6/
  Anton om `menu` ska döljas i comercio när `products` är byggd.
- Röktestets tillfälliga temabyte på business 1 gör svitkörningen ännu
  mindre idempotent mot samma databas (redan noterat i O1:s log) — kör
  alltid mot färsk seed.

Verification: typecheck, lint, `npm test` (13 filer, 203 tester) och
`npm run build` gröna; `npm run smoke` grönt (75 + 9 + 16 kontroller) mot
MySQL 8.0.46 (färsk migrate + seed); `npm run theme:preview && npm run
theme:shots comercio` kört, ingen overflow i någon variant.
